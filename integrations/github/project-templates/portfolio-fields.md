# Recommended portfolio fields

| Field | Type | Values |
|---|---|---|
| Status | single select | Inbox, Planned, In progress, Blocked, Done |
| Priority | single select | P0, P1, P2, P3 |
| Repository | repository | native |
| Lifecycle | single select | proposed, incubating, active, maintenance, deprecated, archived |
| Criticality | single select | tier-1, tier-2, tier-3, tier-4 |
| Target milestone | milestone | native |

Use fields for workflow state. Reserve labels for issue type, domain area, and exceptional risk.
