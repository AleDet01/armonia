# GitHub integration

These assets project the portable Armonìa contract into a GitHub organization.

Apply them deliberately:

1. create the canonical `armonia` repository;
2. create an organization `.github` repository;
3. replace owner/team placeholders;
4. create custom properties;
5. import rulesets in evaluate mode;
6. pilot against non-critical repositories;
7. move rulesets to active enforcement;
8. pin all caller workflows to immutable Armonìa commits.

Some organization features depend on the selected GitHub plan. Core Armonìa conformance does
not depend on them.
