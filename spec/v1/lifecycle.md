# Lifecycle

| State | Meaning |
|---|---|
| `proposed` | Registered idea; no implementation or support guarantee |
| `incubating` | Under active discovery and subject to change |
| `active` | Supported and actively developed |
| `maintenance` | Supported with limited feature development |
| `deprecated` | Replacement or end-of-life has been announced |
| `archived` | No further work is planned |

Lifecycle, maturity, criticality, and health are independent dimensions. A maintenance
project can be healthy; an active project can be unhealthy.
