# Task skills

Task-specific skills may package repeatable workflows, references, and safe helper scripts.
They must:

- declare scope and trigger conditions;
- defer to `AGENTS.md` and repository policy;
- avoid embedding secrets or environment-specific credentials;
- be versioned and evaluated;
- remain optional unless selected by an explicit governance profile.

Armonìa 1.0 does not impose a vendor-specific skill packaging format.
